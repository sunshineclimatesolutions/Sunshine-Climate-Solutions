# 90-day content plan — September 2026

Strategy and query/page mapping for the first 90 days of the organic content program.
This file answers **what to talk about, for which query cluster, on which owning page, with
which CTA**. The recurring production/distribution rules live in
`docs/marketing/CONTENT-OPERATING-SYSTEM.md`; the week-by-week execution tracker is
`docs/marketing/90-DAY-CONTENT-CALENDAR.csv`.

## Principles (unchanged from the original plan)

- **One owning page per query cluster.** Every piece points at the single page that owns the
  intent; clusters are expanded on the owning page, never duplicated into new pages.
- **No doorway content.** No city-page farms, no near-duplicate pages, no thin templated
  posts. The Spring Hill hub is the only location page (see `LOCAL-PAGE-ROADMAP.md`).
- **No keyword stuffing.** Titles, descriptions and on-page copy are written naturally; the
  exact-match phrase is never looped.
- **No generic filler.** No "10 summer tips", no AI content dumps, no invented lists.
- **No fabricated jobs, results, reviews, counts, response times, or outcomes.** Field
  footage, photos and measurements must be genuine (Field Proof rules in the operating
  system).
- **Real customer questions, real HVAC expertise.** Every piece starts from a question a
  homeowner, contractor or property manager actually asks.
- **One clear CTA per content item.** Never stack multiple asks.

## Field Proof series (strategy view)

Field Proof is the permanent recurring proof series: one real photograph, one 10–30 second
vertical clip, one meaningful measurement and one plain-language explanation from legitimate
jobs where recording is appropriate. It feeds every owning page's proof layer (repair,
airflow, maintenance, replacement, commercial, TAB) and every distribution channel. The
capture rules, privacy rules and distribution list live in
`docs/marketing/CONTENT-OPERATING-SYSTEM.md`; the weekly Field Proof slot is tracked in the
calendar CSV. Field Proof is never scripted or staged, and measurements are never presented
as universal standards — context is always explained.

## UTM and attribution

Every post or video description that links to the website uses the exact prepared
platform/service link from `docs/marketing/UTM-MASTER-LINKS.md` (owner cheat sheet:
`WHERE-TO-PASTE-UTM-LINKS.md`). No one-off UTM naming is invented; internal navigation,
canonicals and the sitemap stay UTM-free. Google Ads remains auto-tagged and separate. See
the operating system for the per-platform link mapping.
