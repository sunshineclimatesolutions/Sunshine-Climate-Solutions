### How the icons are rendered

- **Instagram, TikTok, YouTube, X** are inlined by `src/components/SocialIcon.astro`
  (path data copied exactly from the Simple Icons files above) and rendered in a
  single brand color so they sit consistently beside the existing full-color
  owner-supplied logos: Instagram `#e4405f`, TikTok `#000000`, YouTube `#ff0000`,
  X `#000000`. On dark surfaces the black glyphs (TikTok, X) receive a white
  tile, the same defensive treatment already used for the black Yelp wordmark.
- **Facebook, Nextdoor, Yelp** keep their existing owner-supplied graphics in
  `public/images/` (unchanged — the social-expansion directive requires
  preserving them).
- **Gab** uses the official wordmark SVG above, unmodified.
- Simple Icons SVGs ship with a `<title>` element and no fill; the stored files
  are unmodified, and the component renders the path with `aria-hidden` because
  the visible platform label already carries the accessible name.

## Rules applied

- No images scraped from Google Images; no third-party hotlinking.
- Official assets preferred (Gab); reputable open icon source used where an
  official web-icon format is not conveniently available (Simple Icons, CC0).
- Assets stored locally; SVG preferred; no fonts bundled; no brand packages
  downloaded beyond the single SVG files above.
- Trademarks remain the property of their owners; every mark links only to the
  company's own official profile.
