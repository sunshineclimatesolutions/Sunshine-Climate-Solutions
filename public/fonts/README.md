# Self-hosted fonts

Both families are downloaded from Google Fonts as variable WOFF2 files
(latin subset) and are used under the SIL Open Font License.

| File | Family | Weights | License |
| --- | --- | --- | --- |
| `archivo-var-latin.woff2` | Archivo (headings) | 500-800 | `ARCHIVO-OFL.txt` |
| `publicsans-var-latin.woff2` | Public Sans (body) | 400-700 | `PUBLICSANS-OFL.txt` |

To update a font, request the latin subset CSS with a modern browser
User-Agent from `https://fonts.googleapis.com/css2?family=<Family>:wght@<range>&display=swap`,
download the woff2 URL from the `/* latin */` block, and replace the file here.

The Open Font License permits redistribution of these files together with this
project as long as the license texts stay alongside them.
